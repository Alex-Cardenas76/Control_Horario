# Skill RPSoft UI - Guía de Uso

Esta skill configura automáticamente a Antigravity para seguir nuestros estándares de diseño (Azul/Negro) y código (React/Tailwind).

## ¿Cómo funciona?
Antigravity detectará automáticamente cuando pidas generar componentes visuales (botones, formularios, layouts) y aplicará:
- Botones Negros con texto blanco.
- Fondos claros (Slate-50).
- Estructura Dashboard.

## Cómo probarla (Evidencia)
Escribe un prompt como:
> "Crea un botón de 'Iniciar Sesión' para el dashboard"

El agente debería responder:
> "Utilizando la skill RPSoft UI..." y generar el botón con clase `bg-black`.
